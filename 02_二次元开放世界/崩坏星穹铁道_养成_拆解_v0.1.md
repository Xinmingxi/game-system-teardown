> **数据与置信度**：版本号由用户确认。官方 4.6 更新说明页为动态渲染、第三方站点多处 403，全文未取到，所以本稿把数值分成三类：【游戏规则】指版本无关的机制（体力恢复、部位数、等级上限）；【第三方】指攻略站测算，会标来源年份；【待补】指必须实测或等官方公示的空。凡结论靠【第三方】撑着的地方，后面都写明了它撑得多牢。

## 0. 一句话结论

> 它真正解决的是「把一次抽卡变成六周的上线理由」；最危险的地方在于数值膨胀让沉没成本贬值，于是官方只能靠「加强老角色」打补丁。

## 1. 体验目标

**它想让玩家产生什么感受？**（MDA 八选二到三）

圈 **挑战 · 表达 · 发现（弱）**。

- **挑战**之所以是主菜，因为游戏本身是回合制，操作空间被压缩到几乎没有，所以「打不打得过」只能由数值来解释。混沌回忆、虚构叙事、末日幻影、异相仲裁这四张考卷，考的全是练度，于是养成成了给这根主干供血的管子。
- **表达**之所以排第二，因为玩家能替自己回答「我是谁」的地方只剩资源分配：练谁、行迹先点哪条、遗器走速度还是走暴击。打不过可以换配队，但「我把谁练到满星魂」换不了，所以表达必须落在有限的材料上。
- **发现**最弱，因为遗器只有随机、没有新规则，所以新本开完那几天有新鲜感，之后就没东西可发现了。

**不主打感官**，因为养成界面只有数字跳动和材料图标；这层故意做薄，好让成本藏在「数字很爽」后面。

**目标玩家是谁？**

成就型为主（要满星、要练度），探索型次之（研究词条与配队）。社交型与杀手型不买账，因为养成是纯单人行为，没有任何强制互赖。

**如果砍掉这个系统，游戏会缺什么？**

会缺三样，而第三样最致命：

1. 抽卡失去意义——因为练不出东西，抽来只能看；
2. 深渊失去门槛——因为考卷没有分数线，难度投放全落空；
3. **版本内容失去消化容器**——主线 6~8 小时打完，剩下五周半全靠「把新角色练好」把人按在游戏里。

由此可以推出养成的真实职责：它不比「让角色变强」更像一件事，它做的是**给付费结果配一段足够长的等待期**。

## 2. 系统边界

**它管什么、不管什么？**

- 管：单个角色的数值转化（等级 / 晋阶 / 行迹 / 光锥 / 遗器 / 星魂），以及消耗性资源（开拓力、信用点、经验书、各色材料）的分配。
- 不管：角色怎么来（抽卡）、数值怎么结算（战斗）、考卷多难（关卡投放）、资源从哪来（活动与副本产出）。

**它依赖谁、被谁依赖？**

因为抽卡负责提供「养谁」的对象、战斗系统负责提供「强弱」的判据、关卡负责提供「够不够」的分数线，所以养成只能夹在中间做转换器；反过来，深渊四件套与活动关卡又都假设玩家有一支练好的队伍，所以它们全都依赖它。

边界一乱就串味：不少拆解把「抽卡概率」「深渊奖励」写进养成，那是因为把上游和下游当成了系统本身。

## 3. 结构与循环

模块一共七件套：

```
角色等级(1-80, 六次晋阶) —— 经验书 + 信用点 + 晋阶材料
行迹树(普攻6 / 战技·终结技·天赋各10 / 秘技1 + 3个额外能力 + 属性节点)
光锥(1-80, 叠影5) —— 光锥经验 + 进阶材料
遗器(6部位 = 4件套 + 2位面饰品, 各+15, 副词条强化5次)
星魂(0-6) —— 抽卡产物，不属于可刷资源
均衡等级(1-6, 阶梯掉落)
开拓力(上限240, 6分钟/点)
```

主循环：

```
开拓力(存量) → 刷本(流量) → 材料/经验 → 角色战力(转换)
      ↑                                        ↓
      └── 星琼/资源 ← 深渊满星 ← 更高难度(验证)
```

三条支循环：

1. **遗器循环**（无终点）：刷 → 出 → 强化 → 副词条歪 → 再刷。因为没有任何保底，所以它永远不进「毕业」。
2. **周本循环**（周限）：历战余响每周 3 次，产出行迹顶级材料，于是它卡住了所有角色的 8→10 段。
3. **抽卡→养成循环**（跨系统）：抽到人 → 六周练完 → 需要新考卷 → 官方出新深渊 → 需要新人。

**这个循环转一圈要多久？**

- 日常循环 **1 天**：开拓力 240 点一天回满，不刷就是浪费，所以玩家被迫每天开一次。
- 单角色成型 **2~6 周**：满练【第三方】约 9800~10500 开拓力，自然回体 240/日，所以约 41~44 天；只求「能上场」约减半，20 天上下。
- 版本循环 **6 周**：因为一个版本刚好够练出 1~2 个角色，所以卡池节奏和养成节奏落在同一根时间轴上。

这三个尺度对齐不像巧合：**因为版本周期是 6 周，所以单角色成本被设计成 2~6 周**。

## 4. 资源流与经济

| 资源 | 从哪来（产出） | 到哪去（回收） | 卡在哪（瓶颈） |
| --- | --- | --- | --- |
| 开拓力 | 6 分钟/点，上限 240；燃料 1 个 = 60 点；活动与大月卡 | 拟造花萼 10、凝滞虚影 30、侵蚀隧洞·位面饰品 40、历战余响 30 | **硬上限 240**，不刷就溢 |
| 信用点 | 花萼·金、活动、深渊 | 升级、行迹、遗器强化（主要黑洞） | 长期玩家大多溢出 |
| 角色经验书 | 花萼·赤、活动 | 角色 1-80 | 与信用点一起构成「明面成本」 |
| 晋阶/行迹材料 | 花萼、凝滞虚影 | 六次晋阶、行迹节点 | 因为按均衡等级卡掉落，所以低均衡刷不到高级货 |
| 周本材料（历战余响） | 每周 3 次 | 行迹 8→10 | **周上限**，全角色共用 |
| 遗器 + 遗器经验 | 侵蚀隧洞、位面分裂（4.6 限时双倍）、合成 | 刷新词条、强化 | 因为纯随机，所以没有毕业线 |

**有没有通胀风险？**

有，但不在货币上：信用点和经验书对老玩家长期溢出，说明明面货币根本没被当成稀缺资源。真正稀缺的是三件**不可囤积**的东西：

1. **新角色专属材料**，随版本轮换，只能刷当版本的花萼；
2. **周本材料**，周上限 3 次，全角色共用；
3. **随机副词条**，没有上限，也没有保底。

所以这套经济不属于通胀型，属于**「稀缺品轮换」型**：因为官方每 6 周换一批「只有新角色要」的材料，所以老玩家的仓库会周期性归零，通胀压力被转嫁成了追赶压力。

## 5. 关键参数（只写 3~5 个）

| 参数 | 数值 / 形状 | 它在控制什么 | 调大 / 调小会怎样 |
| --- | --- | --- | --- |
| 开拓力日供给 | 240 点/日，6 分钟/点，**线性恢复 + 硬上限** | 整个系统的节流阀 | 调小则养成周期翻倍，抽卡意愿跟着掉；调大则六周练满四个，版本内容被提前吃完 |
| 单角色全养成成本 | 【第三方】满练 ≈ 9800~10500 开拓力；**分段陡增**（70→80 单段 276.3 万经验，行迹 8→10 骤增） | 「练一个」的时间预算 | 调小则获得满足的链条变短，付费冲动更频繁；调大则抽到即仓库 |
| 行迹投入曲线 | **分段 + 后段指数**：7 级前便宜，8→10 要紫材 + 周本材料 | 逼玩家做取舍，制造「关键技能」概念 | 调平则所有技能都能点满，取舍消失，「build」这个概念也跟着消失 |
| 遗器副词条 | **对数收益 × 线性成本**：+3/+6/+9/+12/+15 五次滚点，前三次收益最大 | 长草期的体力去处 | 改成自选则挫败消失，但「每天上线刷两把」的理由也消失 |
| 均衡等级 | **阶梯**（不是斜坡）：每级掉落跃升，需完成对应任务解锁 | 卡住「先练还是先升」的顺序 | 改成连续曲线，则策略性下降，玩家不再有「先别升均衡」的算计 |

> 四个形状记一句话：**体力线性、经验分段、行迹后段暴涨、遗器对数**。

## 6. 反馈回路与时间尺度

- **增强回路**：战力↑ → 深渊满星↑ → 星琼与资源↑ → 抽卡↑ → 新角色↑ → 新养成需求↑。因为每圈都要一个新角色，所以一圈约 **6 周**。
- **调节回路**（三条，都很硬）：
  1. 因为开拓力上限 240 且只线性恢复，所以每天只发一张定量的票；
  2. 因为周本材料周上限 3 次，所以想练快也快不过一周；
  3. 因为副词条纯随机，所以越接近毕业越难涨，边际收益自然递减。
- **延迟在哪里**：抽到角色到真正能上场，中间隔 **2~6 周**。这个延迟是全系统最重要的设计物：它既是留存，也是付费点——买体力、买材料，买的都是「缩短延迟」。

## 7. 动机与心理机制

- **自主中上**：养谁、行迹先点哪、遗器走速度还是暴击，全是玩家的账。因为资源有限，所以每个选择都真排他；因为有排他，才有「这是我的选择」。
- **胜任最强**：深渊满星给出极清晰的反馈——数字够就过，不够就不过，没有任何操作可以赖。
- **关联最弱，几乎为零**：因为养成是单人行为，谁也不欠谁，所以它压根不承担社交。

**最强的胜任 + 最弱的关联 = 一个「适合独狼、不适合社群」的系统。** 这不是失误：社交被交给了别的系统，所以养成可以放心放弃它。

## 8. 难度、节奏与学习曲线

- **学的内容**：资源的机会成本（先养谁）、行迹优先级（哪个技能是命门）、主词条 vs 副词条（什么时候该停）、速度阈值线（卡不卡在某个档位）。
- **学完大概在第几小时**：30~60 小时，也就是开荒结束、第一支队伍成型之后。【待实测】
- **学完之后靠什么继续**：官方每轮换三样新容器——新角色（新 build）、新遗器本（新词条组合）、深渊轮换（新分数线）。因为每次都给一个新容器，所以「学完了」不会立刻变成「走了」。

这也是这套系统最聪明的一手：它不靠加数值延长寿命，靠**换容器**延长寿命。

## 9. 商业与运营耦合

- **付费点在循环的哪个位置**：不在养成里，在上游的抽卡。养成本身只卖「缩短延迟」（燃料、大月卡、无名勋礼），而且**买体力有上限**——因为无限买体力等于取消养成周期，所以这条线被刻意焊死。
- **免费玩家走到哪一步会被卡**：不卡在「养不起」，卡在「养不过来」。因为角色增速快过体力增速，所以**抽到即 1 级**成了常态。这个卡点很微妙：它不阻止你玩，它让你「有但用不上」。
- **活动怎么利用这个系统**：4.6 的「位面分裂」是标准动作——位面饰品限时双倍掉落。因为双倍只在窗口内有效，所以活动制造的不是更多产出，是「错过就亏」的时间压力，于是玩家攒的体力会在那一周集中烧掉。

## 10. 反事实推演（必做）

**假设 A：开拓力日供给从 240 砍到 120。**

因为养成周期会从 2~6 周变成 4~12 周，所以一个版本连一个角色都练不完。玩家的反应不会是「更珍惜体力」，而是**同时只养 1~2 个，其余抽到放仓库**；抽卡意愿随之下降，因为抽了也用不上。所以体力不是独立的付费点，它是抽卡的配套设施——动它，掉的是抽卡收入。

**假设 B：砍掉遗器副词条的随机，改成词条自选。**

因为长草期「每天刷两把」的理由消失，所以深渊满星率上升、挫败下降、满意度上升。但代价是官方少了一个**可以无限投入、永远不达标的容器**。所以随机副词条的本质不像「坑钱」，它更像「给时间一个去处」——把没有内容的六周，换成有目标的六周。

**假设 C：搬到 MOBA（王者荣耀）去。**

不成立。因为养成的前提是「数值可累积、且不可逆」，而 MOBA 每局重置、赛季清零，所以把养成搬过去等于把「等待」搬进一个要求「立刻公平」的场子，两边都崩。

## 11. 崩坏预演

**最可能的死法：膨胀（数值膨胀 → 沉没成本贬值）。**

- **机制推演**：新角色强度↑ → 深渊与虚构的分数线随之上调（敌人血量与机制一起抬） → 老角色即使满练也打不满 → 「我练了六周的东西变废纸」 → 玩家从「按喜好练」退到「只抽新的」 → 抽卡从「选择」变成「订阅」→ 一旦断订阅，直接离开。
- **早期信号**（这套系统已经出现三条）：
  1. 深渊满星分数线每个版本稳定上移；
  2. 社区冒出「满练老角色打不满」的帖子；
  3. **官方开始系统性加强老角色**——4.x 的「砺烁新辉」：4.0 花火、黑天鹅，4.2 流萤、藿藿、希儿、瓦尔特，连星魂一起加强。

第 3 条是关键证据：**如果数值没有膨胀，就不需要加强老角色，所以加强这个动作本身就是膨胀的确认书。** 它只能延缓、不能阻止，因为加强完之后，新角色还得更强才卖得出去，于是下一轮继续。

**次要死法：躺平（追赶成本过高）。** 因为新玩家面对四十多个角色、每个 2~6 周，追赶成本以年计，所以官方必须给新手加速（均衡等级追赶、活动送满练、主角免费换命途）；否则新号会只做主线、不碰养成，那就是养成系统在新用户侧的死亡。

## 12. 横向参考

| 游戏 | 它怎么做的 | 差异点 |
| --- | --- | --- |
| 原神 | 圣遗物同源随机，但体力上限更低、突破材料要跑大地图采集 | 因为星铁把所有产出收进副本，所以它比原神更彻底地做成了「体力换数值」，没有跑图这层缓冲 |
| 明日方舟 | 精英化 + 材料合成链，稀缺来自「合成深度」 | 因为稀缺可预期（能算清还差几个），所以它的挫败感比星铁低——星铁有一部分稀缺不可预期（副词条） |
| 阴阳师 | 御魂随机词条，同源设计 | 因为御魂可交易可回收，所以阴阳师把随机成本分摊给了市场；星铁遗器完全封闭，成本全压在自己身上 |

一句话：星铁是把「随机词条 + 体力闸门 + 版本轮换稀缺品」三件套做到最纯的那一个。

## 13. 我的判断

- **保留行迹 8→10 的陡增**：因为它逼玩家做取舍，是「build」这个概念的物理来源；一旦调平，所有技能都能点满，玩家就没有「我这样配」可说了。
- **砍掉遗器副词条的五次滚点**，改成分段自选或保底。理由不在「对玩家好」，而在于它制造的挫败大于它制造的期待；而且它是「用时间换概率」的偷懒解法，所以同样的六周，官方完全可以用新遗器本、新机制来填。
- **我会怎么改**：新角色到手给一周的养成折扣（材料折扣或体力返还）。因为现在最大的裂缝是「抽到即仓库」——付费的快乐和养成的满足之间隔了六周，中间那段纯负体验，所以折扣不改总成本、只改「刚抽到那周」的手感。
- **如果我是这个项目的策划，下一步会动哪里**：动抽卡与养成的落差，不动体力。因为体力一动，抽卡收入跟着掉；落差一动，只动体验、不动收入结构。
