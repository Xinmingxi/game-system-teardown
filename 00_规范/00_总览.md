# 游戏系统拆解 · 总览

## 一、这套库是什么

目标只有一个：**攒出系统策划能拿得出手的判断力，以及能证明它的作品。**

每拆一个系统，产出三样东西：

1. 拆解文档（Word）——作品本身
2. 一份知识讲解（Word）——它背后的理论，也是你的讲解能力证明
3. 索引登记——让别人（和未来的你）一眼看到攒了多少

## 二、分类依据

传统品类名（MMORPG、卡牌、MOBA）只是**入口**，真正的分类依据是「核心循环相似度」——循环越像，系统骨架越像，能互相复用的经验就越多。

所以这套目录回答的问题是：**我拆的这个系统，在别的品类里长什么样？**

每个品类文件夹的 _清单.md 里写了该品类的核心循环与必拆系统。分类逻辑在那儿，不在目录名上。

## 四、命名规范

### 文件夹

`NN_品类名`——两位序号 + 下划线 + 中文名。序号负责排序，中间留空位方便以后插新品类。90 / 99 / 20 是特殊区，不参与排序。

### 单份拆解

`游戏名_系统名_拆解.md` 与 `游戏名_系统名_拆解.docx`，同目录同名，一份工作稿一份正式稿。

- 游戏名用官方简体中文名，标点全部去掉：崩坏：星穹铁道 → 崩坏星穹铁道
- 系统名必须从词表里选，不要自己发明
- 定稿加 `_v1.0`，未定稿留 `_v0.1`

示例：

- 原神_抽卡_拆解.docx
- 率土之滨_经济_拆解.docx
- 王者荣耀_匹配_拆解.docx

### 知识文档

- 理论卡：`理论/T-001_概念名.docx`（借来的）
- 经验卡：`经验/E-001_一句话断言.docx`（自己得出的）
- 反例卡：`反例/C-001_一句话.docx`（判错过的）
- 配套讲义：`讲义_游戏名_系统名.docx`
- 编号只增不减、不重排；库存与比例看 `20_知识库/_索引.md`

### 什么时候开子文件夹

同一个游戏攒够 5 份拆解，才给它开 `游戏名/` 子文件夹。之前全部平铺——同前缀天然排在一起，平铺更好找。

## 五、文件格式规则

- **正式稿一律是 .docx**。md 只是工作稿，方便改。
- docx 由 md 转换生成，**不要手改 docx**——下次转换会覆盖掉。
- 要改内容：改 md → 重跑转换 → 得到新的 docx。
- 转换命令（在库根目录下运行）：

```
python 工具/md2docx.py 01_MMORPG\魔兽世界_经济_拆解.md 01_MMORPG\魔兽世界_经济_拆解.docx
```

## 六、开一次拆解会话的流程

1. 新会话第一句说清楚：**「按规范拆 X 游戏的 Y 系统」**——这句会命中 `.dsh/skills/game-system-teardown` 技能，不必再交代格式
2. 我会先读 00_规范/01_拆解架构.md 和 02_拆解模板.md，再动手
3. 分工：你出体验和数据（玩过、截过图、有体感），我出结构、参数形状和理论锚点
4. 写完 md → 转 docx → 登记 04_进度索引.md → 抽卡进 20_知识库（T / E / C 三种）
5. 一个品类攒满 3 款，就做一份 90_横向专题 的对比

## 七、三条红线

1. **复述 ≠ 拆解**：说得出「白绿蓝紫橙」不算，要说得出「为什么是五档」
2. **必须回答「如果不这样会怎样」**：至少做一次反事实推演
3. **必须写「运营一年后它会在哪崩」**：这是策划和玩家最大的分水岭

## 十、版本控制与自动保存

- 仓库根目录就是本库根目录，分支 `main`
- `.docx` 也在版本控制里——它是交付物，不是中间产物
- 每 2 小时由 Windows 计划任务「游戏系统拆解-自动保存」跑一次 `工具/autosave.ps1`：有改动就提交，配了远端顺带推送
- 运行日志写在 `.autosave.log`（已 gitignore，不会自己制造提交）
- 提交身份：Xinmingxi <1696737769@qq.com>，与作品集仓库一致；历史已重做成一个干净的根提交
- 远端：https://github.com/Xinmingxi/game-system-teardown.git
- **仓库要先在 GitHub 网页建一个空库**（不要勾 README / .gitignore / license，勾了会冲突）
- 首次推送：`git push -u origin main`，本仓库已设 `credential.helper=manager`，第一次会弹浏览器登录
- 没凭据时 autosave 会立刻失败并记一行「push failed」，不会卡住；补上凭据后下一次自然成功
- 手动保存随时可以：`powershell -File 工具/autosave.ps1`
